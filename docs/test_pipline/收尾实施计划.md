# 测试 pipeline 收尾实施计划

本文补充测试 pipeline 的 PR-AUC、Phenix 预生成、baseline 高分位网格和验证顺序。整体工程边界见 `实施计划.md`；运行命令见 `运行指导.md`；指标和配置组织见 `general.md`。

## 1. PR-AUC

### 1.1 计算范围

PR-AUC 只在 `protein_110 fixed test` 阶段计算一次：

```text
Stage1: compute_pr_auc = false
Stage2: compute_pr_auc = false
Test:   compute_pr_auc = true
```

只接二分类前景路径；多分类 class-view 路径显式关闭 PR-AUC。

### 1.2 指标定义

```text
valid = hardmask == 0
score = ligand_pred[valid]
label = gt_ligand_mask[valid]
AP = Σ (R_n - R_{n-1}) * P_n
```

实现位置：`src/inference/voxel_evaluator.py::evaluate_voxel_pr_auc`。

空 GT 样本返回：

```text
pr_auc = None
```

这些样本不计入 `pr_auc_macro`。

### 1.3 输出

per-sample 输出：

```text
pr_auc
```

落盘位置：

```text
best_summary["per_sample"][*]["pr_auc"]
per_sample_best_metrics.json -> metrics.pr_auc
best_outputs/<sample>/metrics.json -> pr_auc
```

summary 输出：

```text
pr_auc_macro
pr_auc_num_valid
```

## 2. baseline 高分位网格

所有 baseline score map 先做 per-sample rank equalization 到 `[0,1]`。threshold 搜索使用高分位网格。

Stage1：

```text
stage1_search_space:
  type: float
  min: 0.97
  max: 1.0
  step: 0.0001
```

Stage2：

```text
stage2_threshold_window_halfwidth: 0.001
stage2_threshold_step: 0.0001
```

DL 配置不使用这组高分位覆盖，保持：

```text
Stage1: 0.00..1.00 step 0.01
Stage2: Stage1 best ± 0.10 step 0.01
```

## 3. Phenix 预生成

Phenix 采用独立预生成脚本：

```text
src/inference/main/generate_phenix_diff_maps.py
```

生成路径：

```text
phenix_output_root/<system>/<sample_name>/phenix_diff_aligned.mrc
```

共享派生函数：

```text
derive_phenix_map_path(phenix_output_root, system, sample_name)
```

生成端写该路径，消费端按同一规则读该路径。样本 JSON 保持原始输入字段。

### 3.1 receptor-only model

`stardard` 系统使用 `cif_gt_path`，生成脚本会先写 receptor-only mmCIF 作为 phenix model 输入。

`strict` 系统使用 `cif_path`，按系统语义直接作为 phenix model 输入。

receptor-only 生成 util 位于：

```text
src/inference/utils/receptor_strip.py
```

### 3.2 resolution

逐样本优先级：

```text
JSON 显式字段 resolution
> CSV 查表
> fallback_3.5
```

落到 fallback 时，在 summary 中标注：

```text
resolution_source = fallback_3.5
```

### 3.3 对齐

`generate_one_phenix_diff_map(...)` 负责：

1. 运行 phenix。
2. 找到输出差图。
3. 用 `make_model_grid(target_voxel_size=1.0)` 对齐到 `load_from_raw_cif` 参考网格。
4. 断言 shape 和 origin 与 reference 一致。
5. 写 `phenix_diff_aligned.mrc`。

## 4. baseline cache 接线

`src/inference/main/build_baseline_cache.py`：

1. phenix 分支按 `phenix_output_root + system + sample_name` 派生差图路径。
2. density-channel 分支调用 `src/datasets/density_channel_builder.py` 生成 raw score。
3. 所有 baseline 统一执行 `per_sample_rank_equalize`。
4. 写 DL-compatible `.npz`。
5. meta 记录 `raw_diff_map_path`，用于可视化 sidecar MRC。

`src/inference/main/run_baseline_two_stage.py`：

1. 读取 `configs/infer_or_eval/non_DL/baseline_base_<system>.yaml`。
2. 注入 `base_dir`、`phenix_output_root`、split JSON 和 baseline name。
3. 枚举 baseline × system。
4. 复用 `run_two_stage_then_fixed_test(...)`。

## 5. 配置要求

baseline 基础配置包含：

```text
stage1_search_space
stage2_threshold_window_halfwidth
stage2_threshold_step
phenix_output_root
```

DL 配置包含：

```text
objective_expr = avg_voxel_f1 + global_instance_f1_cov03 + global_instance_f1_cov06
filter_strength = basic
output_heads = ["ligand"]
```

如果启用 `advanced` 后处理，需要同步启用 receptor head，并确认 cache 中有 `receptor_pred`。

## 6. 验证顺序

推荐顺序：

1. `py_compile` 修改过的 Python 文件。
2. grep 确认正式源码/配置使用 `cov03/cov06`。
3. 跑一个已有 DL cache 的三段 smoke。
4. 检查 test `best_summary.json` 中的 `pr_auc_macro`、loose instance、top-K。
5. 检查 `per_sample_best_metrics.json` 和 `best_outputs/<sample>/metrics.json` 中的 `pr_auc`。
6. 跑 phenix 预生成 smoke。
7. 跑一个 density-channel baseline smoke。
8. 跑一个 phenix baseline smoke。
9. 批量跑 DL 与 baseline。
