> 本版由 v3 旧稿 + `.review/c17e6b_最后重构代码_v3_v4_record.md` 的 21 条批注 + 后续多轮讨论整合重写。旧稿已归档于 `CLAUDE/plans/archive/最后重构代码_v3_preRewrite_20260618.md`。

## 0. 总目标与本版关键变化

把 Stage1 的判别路径收成一条短、可解释、可分相冻结增量训练的链路：

```text
voxel backbone
  -> point backbone / voxel-point fusion        （trunk）
  -> real / pseudo 两个轻量最终分类头
       每个头内含一个零初始化 cross-attn 子模块（before -> after 纯残差）
  -> sparse refine head（吃冻结 trunk 的 P/C 特征，默认只吃 before）
```

相对旧稿，本版有四个结构性变化：

1. **训练拆成三相单调冻结级联（1a → 1b → 2）**，每相只载上一相 ckpt 的模型权重、冻得更多。消融按"贵 / 便宜"切开：trunk 在 1a 比，cross-attn 靠 1a-vs-1b 免费对照，refine 全部塞进便宜的 stage2 网格。
2. **取消独立的 cross-attn 消融配置（旧 A1）**：cross-attn 在 1a 锁零、1b 解冻，`1a-best` 即"无 interaction"基线，`1b-best` 即"有 interaction"，直接对照。
3. **trunk 级消融变成 1a 的 4 个并列配置**（主 / 去真实原子 density / 体素硬 scatter / decoder fusion(d4321)），各自从头训。旧 A2/A5/fusion 都归到这里；fusion 从"冻结主干换 hook"（做不到）改成"独立从头训的 trunk 变体"。
4. **candidate 截断防护**：`p_best` 逻辑完全不动，新增"单 BOX 候选下限"`min_candidate_voxels_per_class`（默认 3000）抑制 `p_best` 抖动把候选数压崩。

不做大规模全模型联合重训以外的事；不改数据 label 体系；不改 candidate 选择算法本身（只加下限防护）。

## 2. 最终分类头设计

### 2.1 输入

最终分类头直接消费最后一轮 point backbone 输出，按 `PseudoAtomLayout` 从 `outputs["point_feat_raw"]` 切分：

- real 槽位：`real_feat_before_interaction`
- P 槽位：`pseudo_feat_before_interaction`

如需接收 voxel aux base logit，仍可通过明确开关拼接或残差相加（base 恒 detach），但不恢复 front/back 语义。

### 2.2 统一 cross-attn（两方向复用同一个类）

两个方向逻辑同构，合并为单一模块 `GeometricCrossAttention(query_channels, source_channels, num_heads, radius, max_neighbors, detach_source_feat, act_layer)`，沿用 `PseudoGeometricAggregationV2` 的实现思想：radius 建图、source detach、relative coord、可选 bind probability、scatter softmax、**输出投影零初始化**。

实例化两次：

1. `real_to_pseudo`：query=P，source=real（可吃 detached real bind prob）。
2. `pseudo_to_real`：query=real，source=P。

接线契约（**硬性，必须有单测保证**）：

- 以**纯残差**加回：`feat_after = feat_before + crossattn(...)`，中间不得插 LayerNorm 等破坏逐元素恒等的算子。
- 因输出投影零初始化 + 纯残差，**cross-attn 处于零初始化或冻结态时 `feat_after == feat_before` 逐元素精确成立**。1a 锁零时分类头读到的就是纯 before；1b 解冻后 `after = before + delta`，`delta` 从 0 平滑长起。

推荐配置：

```yaml
interaction_radius: 4.0
interaction_max_neighbors: 48
interaction_num_heads: 4
interaction_detach_source_feat: true
```

零初始化写进代码逻辑，不做可选开关。不再为"关闭 interaction"提供运行期开关或独立消融配置——它由 1a/1b 相位天然给出（§5、§6）。

### 2.3 分类尾部

固定命名：`real_atom_head`、`pseudo_atom_head`。结构 `LayerNorm -> Linear -> act -> Linear -> logits`。

- `real_atom_head` 输出 `atom_logits`；`pseudo_atom_head` 输出 `pseudo_logits`。
- 末层支持 prior bias 初始化（沿用现有 `prior_prob` / `prior_probs` / `prior_prob_point_ligand`）。
- 若开 receptor base logit 残差，末层零初始化使初值等价 base。
- 不再输出 `atom_logits_front` / `pseudo_logits_front`。

### 2.4 outputs 清理

在 `stage1_model.py` 现有 outputs（已核对约 34 个 key）基础上做减法，不另起命名体系。

删除：

- `atom_logits_front`、`pseudo_logits_front`（front/back）。
- `atom_tokens`、`atom_hidden`（重头内部、纯调试）。
- `pseudo_feature` 这个旧名（改为 `pseudo_feat_before_interaction`，避免暗示来自旧 atom head）。

保留（**归属与坐标字段本轮全部留**，含派生量）：

- `atom_logits`、`pseudo_logits`。
- `real_feat_before_interaction` / `pseudo_feat_before_interaction` / `real_feat_after_interaction` / `pseudo_feat_after_interaction`。
- `pseudo_voxel_zyx`、`pseudo_batch_index`。
- 归属/几何：`atom_global_indices`（推理 scatter 回全局原子，**主字段不可替代**）、`atom_coord_local_voxel`、`atom_is_in_core_box`、`atom_target`、`atom_counts` 等。
- `recycle_passes_used` 等 runtime 字段（归到 runtime 分组，见 §7.3）。

## 3. Sparse refine head 重构

### 3.1 输入重命名（P 侧两路，after 改语义）

refine 现状（已核对）P 侧本就两路：`P_point_backbone_feat`（= final point backbone 特征 = before）与 `P_atom_head_feat`（= 旧 atom head `pseudo_feature`）。重构为：

- `P_final_point_feat`：P 的 before-interaction final point 特征（即原 `P_point_backbone_feat`）。
- `P_after_interaction_feat`：P 经 `real_to_pseudo` cross-attn 后、**再强制 detach** 的特征（即原 `P_atom_head_feat` 那一路 re-wire，MLP 拼接管线不动）。由开关 `use_P_after_interaction_feat` 控制。
- `P_voxel_backbone_feat`：P home voxel 的 `voxel_final`。
- `C_voxel_backbone_feat`：C voxel 的 `voxel_final`。
- `voxel_logits`、`candidate_class_embedding`、`relative_coords`：可选。

配置 `inputs` 同步：

```yaml
inputs:
  use_C_voxel_backbone_feat: true
  use_P_final_point_feat: true
  use_P_after_interaction_feat: false   # 默认 off；stage2 的 yes/no 消融轴
  use_P_voxel_backbone_feat: true
  use_relative_coords: true
  use_candidate_class_embedding: false
  use_voxel_logits: true
```

删除 `use_P_atom_head_feat`；构造参数 `P_atom_head_dim -> P_final_point_dim` / `P_after_interaction_dim`。错误信息、文档同步改名。

### 3.2 与 cross-attn 的解耦契约

**默认 `use_P_after_interaction_feat=false`**，即 refine 只吃冻结 trunk 的 before 特征（且 detach）。此时 cross-attn 在数据流上**物理上无法**渗进 refine，"P/真实原子分类质量"（cross-attn 影响）与"C 质量"（refine 影响）严格可分。加单测：断言 cross-attn 参数变化时 refine 输入逐元素不变（在 after-switch off 下）。

`use_P_after_interaction_feat=true` 时，因 cross-attn 在 stage2 已冻结（来自 1b），after 特征是 before 的**固定变换**，detach 后作为 refine 的额外只读输入——合法且不破坏 trunk 隔离。

### 3.3 零初始化

refine 必须零初始化关键输出增量（residual 末层 / direct 模式的新增 delta / prior bias 或 base-copy 保证初始稳定）。零初始化是实现契约，不做消融开关。

## 4. Candidate 截断防护（p_best 不动）

`p_best` 的计算与更新逻辑**完全保持原样**（validation 网格搜索 best-F1 阈值 → 硬替换 cache）。仅新增"单 BOX 候选下限"防护，抑制 `p_best` 在相邻 ckpt 间 0.7↔0.3 抖动导致候选数崩塌。

- 新增配置 `min_candidate_voxels_per_class`，默认 `[3000]`，**per 候选类**（与 `max_candidate_voxels_per_class` 对称）。
- **仅作用于 `adaptive_threshold` 模式**（warmup 走 fixed top-c、topk 走 max_count、recorded 暂不用）。
- 公式（`candidate_set.py` adaptive 分支，主配置 `max_count=25000`、`expand=5.0`，`3000 < 25000` 故防护有效）：

```text
target_before_cap = ceil(n_best_box * expand_factor)
target_count = min( max(target_before_cap, min_floor), max_count, numel )
```

即 floor 只抬下界，**撞硬上限或本 BOX 可用体素数时上限优先**（BOX 体素不足 3000 就全取）。

## 5. 三相训练编排（单调冻结级联）

### 5.1 模型注册与加载契约

- **始终构建完整模型**（trunk + 两头含零初始化 cross-attn 子模块 + refine），**所有参数恒注册**，只用 freeze 名单控制可训，不做条件注册。⇒ 每次跨相加载 `unexpected=0`、`missing=0`。
- 跨相只载 model 权重（新增入口 `train.init_from_best_ckpt` / `init_from_best_strict`），**不恢复 optimizer / scheduler / global_step**。
- 每相 **fresh warmup、peak ≈ 3e-5**（沿用 `warmup_plateau`；1b、2 只训小模块，peak 可后续微调，但**不得继承上一相衰减到 ~1/16 的末期 lr**）。
- 每相**独立 run 目录**，run name 编"相 + 变体"；自动/手动选优只在对应目录内挑 best ⇒ 阶段产物天然不混淆（无需 step 偏移或 R 前缀）。
- 启动打印：ckpt 路径、loaded/missing/unexpected **计数**（不 dump key 名）+ trainable/frozen 参数计数 + trainable 模块名摘要，用于核对名单恰好等于预期。**跨相加载预期 `unexpected=0`**。

### 5.2 三相冻结表

| 相 | load | 解冻（训） | 冻结 | loss | 产物 |
|---|---|---|---|---|---|
| **1a** | 随机从头 | trunk + 两头分类尾（读 before） | cross-attn（锁零）、refine | atom + pseudo（+ 深监督） | `1a-best` ×4 trunk |
| **1b** | `1a-best` | cross-attn + 两头分类尾 | **trunk**、refine | atom + pseudo | `1b-best`（主 trunk） |
| **2** | `1b-best` | refine head | trunk、两头、cross-attn | refine 网格（§7.1） | 多个廉价 run |

- 1a 是唯一"贵"的相（trunk 全训）；1b、2 都在冻结 trunk 上只训小模块，廉价、可串行。
- 1b 默认**同时训 cross-attn + 头分类尾**（让头适配 `delta`）；更严格的"只训 cross-attn、冻头"为备选。
- freeze 用 name-pattern；trainable 名单含两头、cross-attn、refine 及其各自的 LayerNorm/projection/bias、必要的接口 norm（接口 norm 为 `LayerNorm`，无 running stats，随所属相一起冻/训即可，不单独处理）。

### 5.3 薄包装编排脚本

核心训练抽成一个通用原语，**不掺任何实验编排**：

```python
run_phase(load_ckpt, trainable_patterns, loss_cfg, refine_input_cfg, run_dir) -> best_ckpt
```

具体级联与串行下沉到**单个编排脚本里的一层极薄 driver**（声明式 phase 列表 + 循环）：

- 1a：对 4 个 trunk 配置各跑一次 `run_phase`。
- 选最优 trunk（按 1a 的分类质量，见 §6）。
- 1b：在最优 trunk 上跑一次。
- 2：在 `1b-best` 上跑 refine 网格；**默认一张卡把同一（损失种类 × 正负权重）下的 `use_P_after_interaction_feat ∈ {yes, no}` 配对串行训完不退出**，再换下一对。

设计动机：后续很可能有不同训练方式 —— 换训练方式只改这层薄脚本，核心 `run_phase` 不动。

## 6. 消融矩阵

### 6.1 trunk 消融（@1a，4 个并列、各自从头训）

| 配置 | 改动 |
|---|---|
| `trunk_main` | 主配置（fusion=e234d4、gauss27+5D、density=both 含真实原子 density） |
| `trunk_no_real_density` | 去掉真实原子 density box（`density_cube: pseudo`；该路经 `interface_norm_real_density_to_point` 进 point 特征，确属 trunk 级，故归 1a） |
| `trunk_hard_scatter` | 体素输入改最朴素 hard scatter（`online_pdb_feature_scatter_kernel: legacy`、关 occupancy/centroid；通道数与 voxel backbone 输入同步校验，不闭合就先补配置组、不在代码静默兜底） |
| `trunk_decoder_fusion` | `/model/fusion: d4321`（decoder 侧 hook；独立从头训，非冻结换 hook） |

判优：以各 trunk 的 `1a-best` 分类质量（`atom`/`pseudo` 指标、`pseudo_PRAUC`）择优；只在最优 trunk 上做 1b、2。其余 trunk 停在 1a。

### 6.2 cross-attn 消融（@1a vs 1b，免费）

`1a-best`（cross-attn=0，无 interaction）对照 `1b-best`（cross-attn 训过）。同一冻结 trunk，严格可分，不需要任何独立消融配置。

### 6.3 refine 消融（@2，网格）

见 §7.1。轴 = 损失种类 × 正负权重 × cross-after-feat。全因子 3×3×2 = 18，cheap 但偏多，可按结果剪枝。

## 7. Loss 与日志

### 7.1 Stage2 refine 网格

三轴：

- **损失种类**：`tversky` / `tversky + focal(γ=0 ≡ BCE)` / `tversky + rank`。
- **正负权重**（统一的"正类强调"旋钮，同时映射到 tversky 的 α/β、rank 的正负、BCE 的 `pos_weight`）：`7:3` / `8:2` / `9:1`。
- **cross-after-feat**：`use_P_after_interaction_feat ∈ {yes, no}`。

约束：

- 预测模式、candidate 预算、detach 策略与主实验一致。
- **不新增 loss 类**，只改 `AdaptiveClassificationCompositeLoss` 现有参数（`focal_alpha_*` / `w_focal` / `w_tversky` / ranking 权重等，以代码当前字段为准）；`γ=0` 即用 focal 退化为 BCE。
- refine 仍是 C 级分类项 + 可选 ranking 辅助项（`ligand_sparse_refine_loss` / `ligand_sparse_refine_delta_loss` / `ligand_sparse_refine_w_rank`），注释与命名适配新结构。

### 7.2 P 自身分类能力日志

新增 `val_score/global/pseudo_PRAUC`（复用 wrapper 已有的 `_sample_ligand_pseudo_supervision()`；PRAUC 优先于 accuracy@0.5；二分类不加 `_foreground` 后缀；不重写 CPC diagnostics、不改 candidate 中间产物面板）。

### 7.3 日志归类（移动，不删除）

- `train_loss` 面板只留 loss 与 loss 权重；`recycle_passes` 等 runtime 字段**移动到 runtime 分组**（不是删除）。
- 删 front/back 相关 loss 与 metric。
- 不大搬 CPC 采样中间产物（candidate 数、anchor 数、cap 前后统计、p_best/p_sampling、refined/unrefined 诊断），保持现有面板与命名，除非 front/back 清理被迫连带改名。
