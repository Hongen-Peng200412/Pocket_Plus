## 0. 目标与范围边界

### 0.1 目标
让 sparse refine head 从"停在 identity 的保守修正"变成"真正够得着候选集天花板的有效重排序"，同时把 stage1 的 trunk 训练成 ligand-aware 表征，为 stage2（Emap2lig 式 diffusion 复用虚拟原子）打好基础。

### 0.2 范围内
- candidate budget（CPC）上调。
- sparse refine 损失重设计：recall-biased Tversky + positive preservation + pairwise ranking。
- sparse refine head 主实验改 `direct` 模式 + 非残差分类头的先验初始化机制。
- detach 路由从 2 个耦合开关重构为 3 个正交开关，让 atom/P 监督训练 trunk、refine 隔墙只读。
- 新增 **P（虚拟原子）监督**：监督 P 所在体素是否属于 ligand 区域。
- embed head 体素分支原子投影：三线性 → 3×3×3 各向同性高斯距离加权 + 复用 occupancy/centroid 特征。
- 深监督（前置/后置头）权重按 PSPNet 惯例重设。
- `configs/model/default.yaml` 清理。
- 1 个主实验 + 7 条消融。

### 0.3 范围外
- stage2 / diffusion 本身（仅作为"为什么不改 anchor 采样"的约束依据，见 0.4）。
- anchor sampler 改造：**明确不改**，保持 `unweighted_fps`。理由：P anchors 会被 stage2 diffusion 直接复用为虚拟原子，困难点/不确定点采样会污染 diffusion 的空间先验（详见诊断文档 §4.5）。
- residual scale gate（`refined = base + sigmoid(g)·delta`）：**不上主实验**。
- §6.2 的"读 C recall"：纯离线分析，**不新增任何日志或代码**。

### 0.4 成功定义（验收口径，详见 §4）
主实验"重构成功"= 同时满足：① `val_capped/global/recall` 从 ≈0.486 明显回升；② `val_score/global/refined_F1` 从 ≈0.524 朝旧预算 ≈0.635 走；③ `refined − unrefined` 的 global delta 在末若干 epoch 稳定 ≥0（不再"普遍低"）。

## 1. 主实验完整配置规格

> 主实验 = 一次性上齐全部"猜测最有利"的配置。下表是单一事实源；消融（§3）= 在此基础上只改一项。

### 1.1 candidate budget（CPC）
| 字段 | 值 | 来源 |
|---|---|---|
| `adaptive_expand_factor` | `[5.0]`（从 2.5） | 折中，避免一路回 7.0 那个较难达到的上限 |
| `max_candidate_voxels_per_class` | `[25000]`（从 10000） | 给大 ligand 样本留余量 |
| `warmup_topc_per_class` | `[25000]` | 与 cap 对齐 |
| `max_anchors_per_class` | `[1024]`（从 800） | 更多 P |
| `anchor_to_candidate.num_neighbors` | `8`（从 4） | 每个 C 连更多 P，消息带宽更足 |
| `anchor_sampler.mode` | `unweighted_fps`（**不改**） | 见 0.3 |

机制说明：`candidate_set.py` 的 `adaptive_threshold` 下 `num_C ≈ ceil(n_best_box · expand_factor)`，再被 `min(·, cap, N_valid)` 截断；`n_best_box = count(prob > p_best)`。平均 `n_best_box ≈ 1708`，`5.0×1708 ≈ 8540 < 25000`，故 `expand_factor` 是恢复 C recall 的主杠杆，cap 只对大样本二次生效。

### 1.2 sparse refine 损失
组合：`L_refine = L_cls + w_pos·L_pos_keep + w_rank·L_rank`

| 部件 | 配置 |
|---|---|
| `L_cls`（分类） | `w_focal=0`、Tversky `alpha=0.3, beta=0.7`（recall-biased），沿用 `AdaptiveClassificationCompositeLoss` |
| `L_pos_keep`（preservation） | `w_pos=0.3`、`m_pos=0`；`P_keep = {i∈C : target=正 且 base_prob_i > p_best}` |
| `L_rank`（ranking） | `w_rank=0.3`、`m_rank≈0.5`；`Q_C = 全部正例 × per-sample TopK(base_prob) 硬负例`，按 `candidate_batch_index` 分组 |
| base 来源 | `candidate_logits` / `candidate_prob`（candidate_set 已 detach），不新增 forward 输出 |
| `p_best` 来源 | wrapper 的 `_cached_voxel_ligand_p_best_by_class`（即 `val_uncapped_best/global/p_best`，与 candidate_set 共用） |
| schedule | 三项 refine 损失共用现有 `linear_warmup`（见 1.5） |

公式：
```text
L_pos_keep = mean_{i∈P_keep} max(0, base_logit_i − refined_logit_i + m_pos)
L_rank      = mean_{(i,j)∈Q_C} max(0, m_rank − refined_logit_i + refined_logit_j)
```
说明：preservation 在 `direct` 模式下语义依然成立——它约束"直接预测的 refined logit 别把可信正例压得比 base 还低"；ranking 与残差/直接模式无关。

### 1.3 sparse refine head
| 字段 | 值 |
|---|---|
| `sparse_refine_residual_mode` | **`direct`**（主实验；`residual` 是 A1 消融） |
| `sparse_refine_use_voxel_logits` | `true`（base logits 作为输入特征，direct 下合法） |
| residual scale gate | **不启用** |
| 先验初始化 | direct 模式 → 用 `prior_prob_sparse_refine=0.1`（见 1.7） |

### 1.4 detach 路由（3 个正交开关）
现状 2 个开关耦合（`detach_pseudo_point_feat` 同时管"进 atom head"和"进 refine"，见 `stage1_model.py:229`）。重构为：

| 新开关 | 主实验值 | 含义 |
|---|---|---|
| `detach_real_point_feat_into_atomhead` | `false` | real 进 atom head 不 detach → 受体监督训练 trunk |
| `detach_pseudo_point_feat_into_atomhead` | `false` | pseudo 进 atom head 不 detach → P 监督训练 trunk |
| `detach_pseudo_point_feat_into_refine` | `true` | pseudo 进 refine detach → refine 隔墙只读、自身损失不回灌 trunk |

- `detach_real_point_feat_into_refine`：**直接省略**，不引入这个开关（refine 不吃 real point feat，无消费者）。
- 设计意图：trunk 由稳定的分类监督（voxel ligand + 受体原子 + P ligand）塑形；refine 躲在 detach 墙后，对应"不 detach 会全损失震荡"的既有实验。
- 落到 `configs/model/detach_residual/max_detach.yaml`。

### 1.5 schedule（refine 损失 warmup）
```yaml
start_on_ratio: 0.1   # 从 0.2 提前
warmup_ratio: 0.2     # 从 0.3 缩短
```
P 监督损失**不走 warmup、从头就开**（它是稳的 trunk 分类监督，类比 atom loss）。

### 1.6 P（虚拟原子）监督
| 项 | 决策 |
|---|---|
| 目标 | 二值 ligand 区域归属，用 `target_from_ligand_dist_map` 在 P 所在体素取硬标签（单通道 sigmoid，和 C 的 refine target 同一套） |
| 头 | 独立的 pseudo 分类头（在 `pseudo_feature` 上接轻量 MLP → 单通道 `pseudo_logits`），**前置 + 后置都有** |
| 损失 | 新增 `ligand_pseudo_loss`（复用 composite 风格、单通道） |
| 权重 | `pseudo_loss_front_weight=0.4`、`pseudo_loss_back_weight=1.0`（深监督，见 1.8） |
| 梯度 | 经 pseudo 尾部回到 shared attention stack；因 `detach_pseudo_point_feat_into_atomhead=false` → 一路塑形 point backbone 的 pseudo 槽位（接受与受体监督在 shared stack 上的多任务耦合） |
| 先验 | `prior_prob_point_ligand=0.1`（P⊂C 富集，故 0.1 而非 0.01） |
| 契约 | `pseudo_loss_front_weight>0` 时若 `pseudo_logits_front` 缺失/形状不符 → **raise**（不要静默跳过；见 §5 风险） |
| 消融 | 前后权重 → 0（A2） |

### 1.7 先验初始化 schema（写进 `configs/model/default.yaml` 的 `backbone`）
```yaml
prior_prob_init_enabled: true       # 总开关，默认开；被各头 residual 开关压制（residual → 零初始化、忽略本值）
prior_prob_voxel_receptor: 0.1      # voxel backbone 受体区域头(voxel_aux)
prior_prob_point_receptor: 0.1      # 点云分支受体原子头(前置+后置统一)
prior_prob_voxel_ligand: 0.01       # dense voxel ligand 头
prior_prob_point_ligand: 0.1        # P 监督头(是否位于 ligand area)
prior_prob_sparse_refine: 0.1       # sparse refine 头(在富集的 C 上)
```
- 机制即 RetinaNet/Focal Loss 的 bias 初始化：末层 bias = `logit(π)`（单通道）；多通道则按类别先验 `log(prior_probs)`。
- 压制规则复用现有残差开关：sparse refine `residual` → 零初始化；atom 头 `refine_receptor_from_voxel=true` → 零初始化跳过先验（与现有逻辑一致）。
- 每个头可被自己的 cfg 覆盖类别默认值。
- 主实验取值：sparse refine=direct→0.1、atom 头(max_detach 非残差)→0.1、P 头→0.1、dense ligand→0.01、voxel 受体→0.1。

### 1.8 深监督权重（PSPNet 惯例）
| 路 | front | back | 依据 |
|---|---|---|---|
| atom（受体口袋） | 0.4 | 1.0 | PSPNet α=0.4（辅助头 < 主头），见诊断文档参考资料 |
| pseudo（P ligand） | 0.4 | 1.0 | 同上 |

不取 (1.0,1.0)（那是 Hourglass 对等多预测的情形，不符合这里的前浅后深关系），不取 (0,1.0)（前置头形同虚设）。

### 1.9 embed head（体素分支原子投影）
| 项 | 决策 |
|---|---|
| 基线 | `configs/model/embed_head/point_clipbig.yaml`（当前 point-only；**允许直接在该配置里打开并配置体素分支原子投影**，无需另起 override） |
| 投影 | 新 3×3×3=27 邻域**各向同性高斯**距离加权 scatter：`w_v ∝ exp(−d_v²/2σ²)`，`σ=0.7` 体素，**逐原子归一化** Σ_v w_v=1（质量守恒）；替掉 `soft_scatter_to_voxel_grid` 的三线性权重（三线性的几何偏置是轴对齐的，各向同性核消除之） |
| 附加特征 | 在喂体素分支前 concat：occupancy 2 维（`log(1+N)`、归一化 occupancy）+ 加权 centroid 3 维（`Σ w_v·offset`）= **5 维** |
| 成本 | 27 vs 8 邻域 ≈ 3.4× scatter 操作，中间张量 `(N·27,C)` 为 transient（~百 MB 级、scatter 后释放）；相对 PTV3 attention + voxel conv 为误差级 |

### 1.10 其它组选择
- fusion：`configs/model/fusion/e234d4.yaml`（抽 voxel 编码器 enc2/3/4+dec4+final，film_plus + weighted_cube）。
- density cube：**主配置 = `both.yaml`（双 encoder：P anchor + 真实原子 density 同时启用）**；消融 A7 = `pseudo.yaml`（只有 P 的 density cube，关真实原子那路）。方向别搞反：主=双 encoder，消融=仅 P。

## 2. 代码改动清单（按模块）

> 每项含：动机 / 改动点 / 契约同步 / 风险。带 ⚠️ 的项触发跨文件契约同步（见 §5.1）。

### 2.1 ⚠️ detach 路由重构（2 耦合 → 3 正交）
- **动机**：解开"喂 atom head"与"喂 refine"的绑定，使 trunk 可被监督塑形而 refine 仍隔离。
- **改动点**：
  - `src/model/stage1_model.py`：`__init__` 形参与字段把 `detach_real_point_feat`/`detach_pseudo_point_feat` 换成 `detach_real_point_feat_into_atomhead`、`detach_pseudo_point_feat_into_atomhead`、`detach_pseudo_point_feat_into_refine`。
  - `_apply_point_feat_detach_routing`（约 1857 行）：产出**两份**路由副本——`fused_point_feat_for_atomhead`（按 into_atomhead 开关）与喂 refine 的 `P_point_backbone_feat`（按 into_refine 开关）。命名上明确区分两个去向（见 §6 简化项）。
  - 顶部"detach 与 logit 残差"契约段（约 55–59 行）同步改写。
- **配置**：`configs/model/detach_residual/max_detach.yaml` 改用新 3 开关；`configs/model/default.yaml` 删除旧开关（见 2.6）。
- **风险**：real 进后置 atom head 从 detached 变 not-detached，偏离 max_detach 原"最大隔离"基线 → A4 即此项的回退消融。

### 2.2 embed head 3×3×3 高斯 scatter + 5 维特征
- **动机**：消除三线性轴对齐几何偏置；把"数目/相对位置"显式喂体素分支。
- **改动点**：
  - `src/model/stage1_embed_head.py`：新增 27 邻域高斯距离加权 scatter（建议与现有 `scatter_to_voxel_grid`/`soft_scatter_to_voxel_grid` 合并为参数化单函数，见 §6）；occupancy 2 维沿用 `add_occupancy_channels` 逻辑；centroid 3 维改为软分配加权质心（`compute_voxel_centroids` 的软版）。
  - 打开 point_clipbig 的体素分支原子投影（`embed_voxel_out_channels` 或 online_pdb_feature 路径按新 scatter 接通），确认 lazy in_channels 初始化路径不受影响。
- **契约同步**：embed head 输出通道数变化（+5）会传到体素分支 density 通道拼接处，核对下游通道数。
- **风险**：通道数/显存增长，已评估为可接受。

### 2.3 ⚠️ P 监督头 + `ligand_pseudo_loss`
- **动机**：让 `pseudo_feature` 编码"是否 ligand"，同时塑形 trunk、服务 refine 消息与 stage2 复用。
- **改动点**：
  - `src/model/stage1_atom_head.py`：在 pseudo 尾部增设单通道 `pseudo_logits`（后置）与 `pseudo_logits_front`（前置）；先验初始化按 `prior_prob_point_ligand=0.1`。
  - `src/model/stage1_model.py::_run_atom_head`：输出 `pseudo_logits`/`pseudo_logits_front`；核验最终 mixed 轮前置头确实能看到 pseudo 槽位。
  - `src/wrappers/voxel_point_stage1.py` + `voxel_point_stage1_losses.py`：新增 `ligand_pseudo_loss` 损失项与 `pseudo_loss_front_weight/back_weight`；target 用 `target_from_ligand_dist_map` 在 P 体素取值；**前置权重>0 而 logits 缺失则 raise**（非静默跳过）。
- **契约同步**：见 §5.1。
- **风险**：shared attention stack 被受体+P 多任务共享（已接受）；前置头静默跳过（已用 raise 兜住）。

### 2.4 ⚠️ `LigandSparseRefineDeltaLoss`（preservation + ranking）
- **动机**：给 refine 一个"相对 base 改进"的显式目标。
- **改动点**：
  - `src/modules/losses.py`（或就近新模块）：新增 `LigandSparseRefineDeltaLoss`，吃 `refined_logits / base_logits / base_prob / target / valid / batch_index / p_best / m_pos / m_rank / topk`，输出 `L_pos_keep`、`L_rank`。

  - `tests/test_ligand_sparse_refine_loss.py`：补 preservation/ranking 的形状/边界用例。
- **风险**：`w_pos=w_rank=0.3` 偏强，靠 warmup 与监控兜底；A3 为整体回退。

### 2.5 sparse refine head direct 模式先验初始化

- 复核其它"被专用子配置决定"的项是否也应删除（按"被子配置决定即删"的原则）。

## 4. 验收 / 判读标准

> 无 seed、delta 在 `1e-3~1e-4` 量级，判读规则必须事先固定，否则结论被 epoch 抖动带偏。

### 4.1 主实验"成功"（三条同时看）
1. `val_capped/global/recall` 从 ≈0.486 明显回升（朝旧预算 292668 的 ≈0.75 方向）。
2. `val_score/global/refined_F1` 从 ≈0.524 朝旧预算 ≈0.635 方向走。
3. `refined − unrefined` 的 global delta 在末 3–5 epoch 稳定 ≥0（不再"普遍低"）。

### 4.2 每条消融的判读
- 取**末 3–5 个 epoch 的均值**，不看单点。
- 主实验相对该消融在 `val_score/global/refined_F1` 上的差，需**明显超过同 run 内 epoch 间抖动幅度**，才算"该机制有效"。
- 差落在抖动以内 → 记"该机制在当前数据/算力下无显著收益"，**不强行解读正负号**。
- 三层拆开看（纯离线，不入日志）：`val_uncapped_best/global/best_F1` 看 dense 上限、`val_capped/global/recall` 看候选召回、`refined−unrefined` C-local 差看 head 净效果。

## 7. 风险与回退

| 风险 | 兜底 / 回退 |
|---|---|
| detach 契约失配 | §5.1 同步 + 测试守住；smoke run 暴露 |
