# Stage1推理管线:

先推理产生概率图prob（使用sigma=0.5, stride=30拼接）。接下来的调参&落盘流水线是：


_centered.npz 的第一补充函数：输入prob_map和一个阈值，直接根据26-连通得到blob并落盘对应的空间位置、blob mask内的逐体素概率(由全图划窗推理而来)等基本特征（或者可以顺便额外落盘Matcher里面需要的48^3的概率、原始密度、模拟密度，以及少量几何字段），不补充Find_*系列的特征（如A/P等）。

(1).对于unet_c1，直接用语义 micro-F1 对应的最优阈值落盘一次。
(2).对于Find_*， 先用语义 micro-F1 对应的最优阈值落盘一次，称为F1-centered，再用F3-centered（alpha=3）落盘一次，称为F3-centered。我的意图是：让F1-centered使用下面和unet_c1一样的推理模式（相当于不stage1的推理中使用高斯打分等机制）



_centered.npz 的第二补充函数：
(1).对于Find_*，输入上一步以及落盘的初步.npz，以及一个"最小体素数要求"（默认为8），进行居中推理，补充现有的centered.npz契约里面Find_*的字段。
(2).对于unet_c1，同样输入上一步以及落盘的初步.npz，，以及一个"最小体素数要求"（默认为8），进行居中推理，补充voxel_final特征。

对于Find_*，只跑上面的F3-centered，用来送入下面的高斯打分以及stage2-matcher。注意那些被最小体素要求过滤掉的blob意味着被视为阴性。
注意，之前的契约中有BLOB_EXCEED这个标志，我们或许可以保留这个机制，但是我更倾向于在calbration set / val上使用force模式，训练集倒是可以考虑"偷懒"。




稍稍扩展当前的高斯打分函数，我们用扩展后的高斯打分函数，在calbration set上选参数、用选好的参数进行训练 / 验证 / 留出集的推理。
输入：（probability map, 当前高斯打分中所有的参数，最小体素数, 可选的_cenered.npz中的东西[如A的概率]）。这里的"最小体素数"是要求连通区域的，小于这个数的连通区域将会在打分前就被去除。
两种模式：
(1).完整模式：用于Find_*的F3-centered，读取上面产出的 _centered.npz，先按照最小体素数过滤blob，再按照固定参数打分——————和现在一样。
(2).基本模式：用于unet_c1和Find_*的F1-centered，打分的参数只有3个实则2个了：平均概率的系数、最终得分阈值、最小体素数（前两个自由度其实相当于一个）。


从头到尾只有2个评分函数：
f_1 = micro F1(即micro dice) + covF1 + 1to1F1;
f_2 = micro F2 + covF2 + 1to1F2（F_alpha中alpha=2）
上面两个评分函数都是"micro"系列的（实例级别的指标也是跨越PDB算）。


接下来就是调参流程：
(1).完整模式，用于Find_*的F3-centered对应的推理模式。评分函数是f_2，但是也报告f_1的值作为诊断指标。
当前的高斯打分调参程序是二阶段的，我们给它加上单独的第三阶段：确定最小体素要求。在前面两阶段选好的参数下，最小体素要求这个参数可以多调几个：8, 9, 10, ...., 40。

注意：原本我们在完整模式下就是施加了8作为最小体素要求。选定参数后，最小体素要求自然是这里选中的（因为>8）。

(2).基本模式，用于unet_c1和Find_*的F1-centered的消融。
